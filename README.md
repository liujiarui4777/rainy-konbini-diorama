# 雨夜便利店街角 · 微缩三维模型

一个可以自由拖拽、旋转、缩放的雨夜日式便利店街角小场景。纯前端、零外部资源，双击 HTML 即可打开。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `雨夜便利店街角.html` | **成品**，单文件（约 1.4 MB），three.js 与全部贴图都已内联，可离线直接双击打开 |
| `dist/index.html` | 同上（构建产物副本，方便调试） |
| `preview.jpg` | 效果预览图 |

操作：鼠标左键拖拽旋转 · 滚轮缩放 · 双指拖拽/捏合（触屏）· 静止 14 秒后镜头会自动缓慢环绕。

## 场景构成

- **底座**：26 × 26 m 的正方形，带土层断面（三层色带）与顶沿细亮边，像一块陈列用的模型底座。
- **便利店**（视觉中心，7.2 × 5.8 × 4.05 m）：L 形雨棚、发光主招牌与屋顶广告牌、竖向袖看板、玻璃橱窗、双开自动门、门口地垫、伞架、立牌、花盆、门口光池；室内有货架商品、冷柜墙、杂志架、收银台、天花灯带。
- **街道**：主路 + 侧街形成的街角转折、圆角马路牙子、盲道砖、雨水篦子与排水沟、井盖、路边停车位（含挡车器）、两组斑马线、路面「止まれ」、护栏。
- **街角元素**：两台自动贩卖机、两辆自行车、三色分类垃圾桶、路灯（带投影聚光）、三根电线杆与垂度电线、停止标志与蓝色路牌、公告栏、空调外机、小巷入口与杂物（木箱、啤酒箱、垃圾袋、吊灯、后门）、趴在贩卖机旁的猫。
- **周边**：西侧两层老楼（卷帘门、暖帘、红灯笼、粉色霓虹「スナック」）、东侧商铺（「居酒屋」霓虹、空调、后墙招牌）、街尾建筑、对面小公园（秋千、长椅、小径、地灯、树）、投币停车场（照明杆、精算机）、民居。

## 技术要点

- **三渲二**：`MeshToonMaterial` + 5 阶梯度图做赛璐璐分色；顶点着色器注入的 Fresnel 边缘光；反向外壳描边（屏幕空间等宽）。
- **湿路面**：实时平面镜反射（镜像相机 + 投影纹理矩阵）叠加到自定义地面着色器，配合程序化积水遮罩、雨滴涟漪法线扰动、菲涅耳加权；人行道积水用叠加贴片。
- **雨**：单 draw call 的线段雨（顶点着色器循环下落 + 风偏），另有实例化雨滴溅射水环。
- **后期**：亮度提取 → 两级高斯泛光 → ACES 色调映射 → 移轴虚化（强化微缩模型感）→ 分离色调 + 暗角 + 颗粒。
- **性能**：静态几何按材质合批（约 1300 个网格 → 30 个合并体），DPR 上限 1.3，反射缓冲 768；1440p 下实测约 45–60 fps。

## 重新构建

```powershell
# 需要 Node + esbuild（脚本里已写好本机 esbuild 绝对路径）
.\build.bat
```

源码在 `src/`：`main.js`（入口/相机/灯光）· `world.js`（底座与道路）· `store.js`（便利店）· `props.js`（街角道具）· `district.js`（周边建筑）· `wet.js`（反射与雨）· `post.js`（后期）· `texture.js`（全程序化 Canvas 贴图）· `palette.js`（材质与描边）· `merge.js`（合批）· `kit.js`（几何工具）。
